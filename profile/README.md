# Welcome to the EKI GitHub Organization

This is the home for EKI's shared code, tools, and collaborative projects.

## New to EKI GitHub? Start here

All EKI staff who are new to this organization should begin with the
**[github_intro](https://github.com/EKI-inc/github_intro)** repository. It walks you through:

1. **Onboarding** - the required EKI GitHub Onboarding Gate (policy acknowledgment, training, and access approval)
2. **Training** - hands-on Git and GitHub lessons via two learning paths (GitHub Desktop for beginners, Git Bash for command-line users)
3. **IDE setup** - install guidance for VS Code, Git, GitHub Copilot, Python, and R

> Note: `github_intro` is a private repository. If you cannot open the link, contact Helpdesk and/or a GitHub admin to get invited to the organization first.

## Questions or access requests

Open a **Digital project / IT intake** issue using the issue form, or contact an EKI GitHub admin.
